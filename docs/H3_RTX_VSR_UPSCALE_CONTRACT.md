# H3 Director local RTX Video Super Resolution contract

Status: verified node/dependency contract; end-to-end project-video validation is pending a locally available completed H3 render.

This feature is local-only. It never sends media to a cloud service and it never replaces its source render.

## Verified runtime components

- KJNodes `ImageResizeKJv2` (`KJNodes/image`) exposes `nvidia_rtx_vsr`.
- NVIDIA `nvidia-vfx` 0.1.0.1 is installed only in the configured ComfyUI virtual environment. Its `nvvfx.VideoSuperRes` import and a CUDA 64x64-to-128x128 frame test passed on the NVIDIA GeForce RTX 5060 Ti.
- Video Helper Suite provides `VHS_LoadVideo` and `VHS_VideoCombine`.

## API workflow

The app constructs a three-node ComfyUI API prompt. It is an internal implementation detail and is not shown in the product UI.

1. `VHS_LoadVideo` loads a collision-safe temporary MP4 copied to the configured ComfyUI input directory. It emits `IMAGE`, `frame_count`, `AUDIO`, and video metadata.
2. `ImageResizeKJv2` receives the complete `IMAGE` batch, runs `nvidia_rtx_vsr` on GPU, with `keep_proportion=stretch`, `divisible_by=8`, and an exact 2x target.
3. `VHS_VideoCombine` receives the RTX VSR image batch, original FPS, and `AUDIO` from node 1. It writes `video/h264-mp4`.

The source resolutions generated by H3 Director are multiples of 32; their 2x targets are therefore multiples of 8, as required by the installed RTX VSR implementation.

## Output and provenance

The temporary ComfyUI output is not the user-facing result. H3 Director copies it to:

`scenes/scene_NNN/renders/vNNN/derived/nvidia_rtx_vsr/vNNN/video.mp4`

alongside an atomically written `metadata.json` recording source version, source/output hashes, dimensions, 2x scale, FPS, duration, audio presence, ComfyUI prompt ID, backend, timestamp, and ffprobe result.
